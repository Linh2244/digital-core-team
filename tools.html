Bộ công cụ Bảo mật DigitalCore

Bộ công cụ viết bằng Python thuần của Digital Core team — dò quét, bảo mật web, bí mật, mật khẩu, log và quét phụ thuộc. Chỉ cần Python 3.10+ cho các chức năng cốt lõi; thư viện tùy chọn mở khóa scan raw và kiểm tra mật mã nâng cao.

01Dò quét & Mạng

pyscan.py
Port scanner

Quét cổng nâng cao — quét SYN/TCP/UDP, phát hiện dịch vụ và phiên bản, đoán OS, kiểm tra SSL/TLS sâu và so sánh lịch sử quét cho CI.

python pyscan.py -sT -sV -p 1-1000 example.com Tải Công cụ
dnslookup.py
DNS lookup

Full dig-style DNS lookup in pure Python — every record type, DNSSEC, root-to-authoritative tracing, TCP/EDNS, reverse lookup, and JSON output.

python dnslookup.py example.com --mx --trace Tải Công cụ
subfind.py
Tìm tên miền con

Tìm tên miền con qua Certificate Transparency (crt.sh), brute-force DNS có lọc wildcard và zone transfer (AXFR) — kèm phân giải A/AAAA.

python subfind.py example.com --top 200 --axfr --resolve Tải Công cụ

02Bảo mật Web

httpsec.py
HTTP scan

HTTP security scanner — checks TLS, headers, cookies, methods, sensitive paths, CORS, and redirects, then scores the target 0–100 with an A–F rating.

python httpsec.py --active -oJ report.json https://example.com Tải Công cụ
dirbf.py
Dir brute-force

Web directory and file brute-forcer — 269 built-in paths, custom wordlists, auto file extensions, status-code filtering, redirect capture, and JSON output.

python dirbf.py -w big.txt -x php http://example.com Tải Công cụ
loginbf.py
Login brute-force

Tests username/password combos against login endpoints — HTTP Basic Auth, POST form, JSON, or query string — with success detection by status code or body text.

python loginbf.py --basic -U users.txt -P pass.txt http://example.com/login Tải Công cụ

03Bí mật & Token

secretscan.py
Secret scanner

Scans source code for leaked secrets — API keys, tokens, JWT, private keys, passwords, connection strings — with entropy filtering and allowlists to cut noise.

python secretscan.py . --min-severity HIGH --short Tải Công cụ
jwtcheck.py
JWT inspector

Decodes and audits JWTs — flags alg:none, algorithm confusion, weak HMAC secrets, and key injection, then verifies signatures with a secret or public key.

python jwtcheck.py --secret S3cr3t "eyJhbGciOiJIUzI1NiJ9..." Tải Công cụ

04Mật khẩu & Hash

pwgen.py
Password generator

Cryptographically secure password and passphrase generator built on the secrets module, with strength checks, entropy stats, and JSON output.

python pwgen.py -c 5 -l 20 --no-ambig Tải Công cụ
pwcheck.py
Strength checker

zxcvbn-style password analysis — common passwords, leetspeak, keyboard patterns, sequences, dates — with crack-time estimates and WEAK-to-VERY-STRONG ratings.

python pwcheck.py "Tr0ub4dor&3" --json Tải Công cụ
hashid.py
Hash identifier

Identifies hash types by length, charset, and prefix — lists possible hashes with hashcat (-m) and John the Ripper formats, ready for cracking.

python hashid.py --short e99a18c428cb38d5f260853678922e03 Tải Công cụ

05Log & Giám sát

logsec.py
Log analyzer

Analyzes web and SSH logs for threats — SQLi, XSS, LFI, brute-force, scanners — with severity ratings, JSON/CSV output, and CI-friendly exit codes.

python logsec.py access.log --threats-only --exit-on HIGH Tải Công cụ

06TLS & Phụ thuộc

tlscheck.py
TLS checker

Checks TLS protocol versions, ciphers, and certificates on any service — HTTPS, SMTP, IMAP, LDAPS, and more — with JSON output.

python tlscheck.py --json example.com:443 Tải Công cụ
depcheck.py
Dependency scanner

Scans lockfiles and manifests (pip, npm, Maven, Go, Cargo) against the OSV.dev CVE database — safety score, A–F grade, offline cache, text/JSON/Markdown reports.

python depcheck.py --update requirements.txt Tải Công cụ

Chỉ dùng các công cụ này cho mục tiêu bạn sở hữu hoặc được ủy quyền kiểm tra. Quét hệ thống không thuộc quyền sở hữu có thể vi phạm pháp luật và điều khoản sử dụng của nhà cung cấp — hãy đảm bảo có văn bản cho phép trước khi chạy.
