Essential commands at a glance

Hand-picked commands and shortcuts for Linux, networking, security, and Git — copy them straight into your terminal.

Command Purpose Category
ls -laList all files, including hidden entries, with details.Linux
cd <dir>Change the current working directory.Linux
chmod 755 <file>Set file or directory permissions.Linux
chown u:g <file>Change the file owner and group.Linux
grep -r <pattern> <dir>Search recursively for a text pattern.Linux
find <dir> -name "*.log"Find files by name pattern.Linux
ps auxList all running processes.Linux
kill -9 <pid>Force-stop a process by its PID.Linux
systemctl restart <svc>Restart a system service.Linux
tar -czvf a.tar.gz <dir>Create a compressed archive of a directory.Linux
tar -xzvf a.tar.gzExtract a compressed archive.Linux
ping <host>Test whether a host is reachable.Networking
curl -I <url>Fetch the HTTP response headers of a URL.Networking
ss -tulpnList open ports and listening sockets.Networking
nc -lvnp <port>Listen for connections on a TCP/UDP port.Networking
tcpdump -i eth0Capture network packets on an interface.Networking
nmap -sV -p- <host>Run a full service and version scan.Security
gobuster dir -u <url> -w <wl>Enumerate directories on a web server.Security
hydra -l user -P pass.txt ssh://<host>Brute-force an SSH login with a wordlist.Security
john --wordlist=<wl> hash.txtCrack password hashes from a file.Security
sqlmap -u <url> --dbsAutomatically enumerate databases via SQL injection.Security
python3 -m http.server 8000Serve the current folder on port 8000.Security
git initInitialize a Git repository in the current folder.Git
git add .Stage all changed files.Git
git commit -m "<msg>"Commit the staged changes with a message.Git
git pushUpload local commits to the remote repository.Git
git log --onelineShow the commit history in compact form.Git
